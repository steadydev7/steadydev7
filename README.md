## What I Build

### 🤖 AI & LLM
Retrieval-augmented generation, vector search, prompt design, and evaluation sets for enterprise chatbots and internal knowledge search. OpenAI API, LangChain, pgvector, and grounded-answer guardrails.

### ⚙️ Backend
Node.js / NestJS and Python / FastAPI services with clean domain boundaries. REST APIs, PostgreSQL, MongoDB, Redis, background jobs, and OAuth / JWT authentication.

### 🎨 Frontend
React and Next.js with SSR, ISR, and streaming. Tailwind CSS, typed API layers, accessible component systems, and performance budgets that actually get enforced.

### ☁️ Cloud & DevOps
AWS, Docker, and Kubernetes with CI/CD pipelines on GitHub Actions. Infrastructure as code, containerized deployments, logging, and monitoring.
